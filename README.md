# Rent Compass

Interactive summary of a MAST30034 (University of Melbourne) student project on Victorian rents: what sets the asking rent, where rents may rise over three years, and which Melbourne suburbs are liveable and affordable for a typical renting household.

Open the page: https://h451159143-prog.github.io/Rent_Compass/

This public build uses only public data: Homes Victoria (DFFH) bond medians, ABS Census and boundaries, and OpenStreetMap, plus model-level statistics. It contains no listing rows, addresses or coordinates, and no suburb rent estimated from the course listing data, so the affordability tab can test fewer suburbs than the full analysis.

General information from a student project, not advice. Base date September 2025.
